# ちら見くん 🐣

WordPress（doctor-yamanashi.jp）に入れる前に、HTMLの見え方をスマホ・タブレット・PC幅で確認するための、ひとみ専用プレビューアプリです。

- `index.html` 1ファイルで動きます（GitHub Pagesで公開）
- 貼ったHTMLは、サイトの本物のCSSを読み込んだ枠の中に表示されます
- CSSのURLや外枠は、アプリ内の「設定」から変えられます
- 上のバーの「お知らせ／活動報告／固定ページ・その他」で外枠を切り替えます。「固定ページ・その他」は、ページ名（ヘッダー・パンくず）とサイドバーの有無を自由に変えられます
- 右上のミニ全体像は、上の帯をドラッグで移動、タップで拡大／縮小できます（位置は設定の「ミニ画面の位置を戻す」で初期位置に戻せます）
- 「公開前チェック」は、貼ったHTMLの中身だけを見て、alt抜け・空リンク・全角スペース・半角カナ・仮の文言・閉じタグ漏れなどを知らせます（公開後の表示やリンク先の生死までは見ません）
